## Prices found — ready to write

### OTL Fitness — the best find in the wave
`the-domain` · classes model · **billed every 4 weeks, not monthly**

| Plan | Price | Includes |
|---|---|---|
| 2x per week | $195 | 8 classes per 4-week cycle, no rollover |
| 3x per week | $235 | 12 classes per 4-week cycle, no rollover |
| Unlimited | $275 | Unlimited classes per 4-week cycle |
| First class | $20 | Not credited toward a membership |
| Trial week | $79 | 7 days unlimited; credited if you join within the trial |

`billing_period: "4-week"` — 13 payments a year, the EAAC precedent. Per-class from
the 2x plan is $195÷8 = **$24.38**; the 3x plan is $19.58, which would take the
headline. Source: `otlfitness.com/pricing`.

### Pronto Pilates Arboretum
